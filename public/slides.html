A third pair of tables arrives with the SDK: agent_conversations and its messages.

database/migrations/Schema::create('telegram_chats', function (Blueprint $table) {
    $table->id();
    $table->unsignedBigInteger('telegram_id')->unique();       // who
    $table->string('name')->nullable();
    $table->string('conversation_id', 36)->nullable();       // memory
    $table->timestamps();
});
 
Schema::create('reminders', function (Blueprint $table) {
    $table->id();
    $table->foreignId('telegram_chat_id')->constrained()->cascadeOnDelete();
    $table->string('body');
    $table->dateTime('remind_at');
    $table->dateTime('delivered_at')->nullable();          // sent yet?
    $table->timestamps();
 
    $table->index(['delivered_at', 'remind_at']);
});

No policy class here — the relationship is the authorisation. Scoped this way, the model was never given a way to name another chat's row.

app/Models/TelegramChat.php  ·  app/Models/Reminder.phpclass TelegramChat extends Model
{
    protected $fillable = ['telegram_id', 'name', 'conversation_id'];
 
    public function reminders(): HasMany          // every tool goes through here
    {
        return $this->hasMany(Reminder::class);
    }
}
 
class Reminder extends Model
{
    protected $fillable = ['body', 'remind_at', 'delivered_at'];
 
    public function scopeDue(Builder $query): void       // the scheduler
    {
        $query->whereNull('delivered_at')->where('remind_at', '<=', now());
    }
 
    public function scopePending(Builder $query): void   // the tools
    {
        $query->whereNull('delivered_at');
    }
    protected function casts(): array
    {
        return ['remind_at' => 'immutable_datetime'];  // a real object
    }
}

Setup  ·  Telegram the service layer

Four endpoints is the whole Bot API

sendMessage      the reply
sendChatAction   the typing dots
setWebhook       point Telegram at your URL
deleteWebhook    stop it
setupphp artisan telegram:webhook <url>
secretit prints a TELEGRAM_WEBHOOK_SECRET= line to copy

The token sits in the URL of every call, so scrub it before anything reaches a log.

app/Services/Telegram.phppublic function sendTyping(int $chatId): void
{
    $this->call('sendChatAction', ['chat_id' => $chatId, 'action' => 'typing']);
}
 
private function call(string $method, array $payload = []): mixed
{
    $response = Http::asJson()->connectTimeout(10)->timeout(60)->post(
        "https://api.telegram.org/bot{$this->token}/{$method}", $payload,
    );
 
    if (! $response->successful() || $response->json('ok') !== true) {
        throw new RuntimeException(
            "Telegram [{$method}] failed: ".$this->scrub($response->body()),
        );
    }
 
    return $response->json('result');
}

public function __invoke(Request $request): Response
{
    $secret = (string) config('services.telegram.webhook_secret');
 
    abort_if(
        $secret === '' || ! hash_equals($secret, (string) $request->header(
            'X-Telegram-Bot-Api-Secret-Token'

Code  ·  service

One class knows about both sides

chatfirstOrCreate on the Telegram id
guardan update carrying no text is never answered
tableevery command the bot knows, in one match

Two commands, two arms. The moment one of them takes an argument — /remind … — is the moment to parse before dispatching. Not before.

app/Services/TelegramBot.phpprivate const WELCOME = 'Hi! I am a reminder bot …';
 
public function handle(array $update): void
{
    $message = $update['message'] ?? [];
    $text = trim((string) ($message['text'] ?? ''));
 
    if ($text === '') {
        return;
    }
 
    $chat = $this->chatFor($message);
 
    $this->telegram->sendMessage($chat->telegram_id, $this->reply($chat, $text));
}
 
private function reply(TelegramChat $chat, string $text): string
{
    return match ($text) {
        '/start' => self::WELCOME,
        '/forget' => $this->forget($chat),
        default => $this->ask($chat, $text),
    };
}
Code  ·  service the default arm

Continue the conversation, or start one

typingthe dots cover a model call, so they go out here
agentcontinue on the stored id, or open a conversation
memorystore the returned conversationId

That column is what makes /forget possible. The SDK will happily remember a conversation, but it offers nothing to forget one — so the boundary has to live on our side of the line.

app/Services/TelegramBot.phpprivate function forget(TelegramChat $chat): string
{
    $chat->update(['conversation_id' => null]);
 
    return 'Done, I have forgotten our conversation. …';
}
 
private function ask(TelegramChat $chat, string $text): string
{
    $this->telegram->sendTyping($chat->telegram_id);   // the only slow arm
 
    $agent = new TelegramAssistant($chat);
 
    if ($chat->conversation_id) {
        $agent->continue($chat->conversation_id, as: $chat);
    } else {
        $agent->forParticipant($chat);
    }
 
    $response = $agent->prompt($text);
 
    $chat->update(['conversation_id' => $response->conversationId]);
 
    return $response->text;
}

app/Ai/Agents/TelegramAssistant.phpclass TelegramAssistant implements Agent, Conversational, HasTools
{
    use Promptable, RemembersConversations;
 
    public function __construct(private readonly TelegramChat $chat) {}
 
    public function instructions(): Stringable|string
    {
        return <<<INSTRUCTIONS
        You are a reminder bot living inside a Telegram chat.
        Keep replies short, the way a person texts.
 
        It is {$now->format('l j F Y, H:i')}. Work reminder times
        out against that clock.
        INSTRUCTIONS;
    }
 
    public function provider(): array
    {
        return [config('ai.default'), ...config('ai.failover')];
    }
 
    public function tools(): iterable
    {
        return [new CreateReminder($this->chat), /* … */];
    }
}
Code  ·  tool

A tool is a PHP class the model may call

schemathe arguments it is allowed to send
scopedthe chat is injected, not asked for
returna string — the model reads it next

A failed rule is not an error to log. It is the model's next instruction.

app/Ai/Tools/CreateReminder.phpclass CreateReminder implements Tool
{
    public function __construct(private readonly TelegramChat $chat) {}
 
    public function schema(JsonSchema $schema): array
    {
        return [
            'body' => $schema->string()->required(),
            'remind_at' => $schema->string()
                ->description('as YYYY-MM-DD HH:MM')->required(),
        ];
    }
 
    public function handle(Request $request): Stringable|string
    {
        $validator = Validator::make($request->all(), [
            'remind_at' => ['bail', 'required', 'date_format:…', 'after:now'],
        ], [
            'remind_at.after' => 'That time has gone by. Ask for a later one.',
        ]);
 
        if ($validator->fails()) {
            return $validator->errors()->first();
        }
 
        $reminder = $this->chat->reminders()->create($validator->validated());
        return "Reminder #{$reminder->id} set.";
    }
}

app/Ai/Tools/LogCall.phpclass LogCall implements Tool
{
    public function __construct(private readonly Rep $rep) {}
 
    public function description(): Stringable|string
    {
        return "Log a call against one of this rep's deals.";
    }
 
    public function schema(JsonSchema $schema): array
    {
        return ['deal_id' => $schema->integer()->required(),
                'notes' => $schema->string()->max(500)->required()];
    }
 
    public function handle(Request $request): Stringable|string
    {
        $deal = $this->rep->deals()->find($request->deal_id);
 
        if (! $deal) {
            return 'Not one of your deals. Ask which one.';
        }
 
        $deal->calls()->create($request->only('notes'));
 
        return "Logged against {$deal->name}.";
    }
}

app/Ai/Tools/UpdatePage.phpclass UpdatePage implements Tool
{
    public function __construct(private readonly User $editor) {}
 
    public function description(): Stringable|string
    {
        return 'Rewrite the body of a page.';
    }
 
    public function schema(JsonSchema $schema): array
    {
        return ['slug' => $schema->string()->required(),
                'body' => $schema->string()->required()];
    }
 
    public function handle(Request $request): Stringable|string
    {
        $page = Page::whereSlug($request->slug)->sole();
 
        if (Gate::forUser($this->editor)->denies('update', $page)) {
            return 'You cannot edit that page.';
        }
 
        $page->update($request->only('body'));
 
        return "Updated {$page->slug}.";
    }
}

app/Ai/Tools/AdjustStock.phpclass AdjustStock implements Tool
{
    public function __construct(private readonly Warehouse $site) {}
 
    public function description(): Stringable|string
    {
        return 'Add or remove stock for one SKU at this site.';
    }
 
    public function schema(JsonSchema $schema): array
    {
        return ['sku' => $schema->string()->required(),
                'delta' => $schema->integer()->required(),
                'reason' => $schema->string()
                    ->enum(['damage', 'recount', 'return'])->required()];
    }
 
    public function handle(Request $request): Stringable|string
    {
        $item = $this->site->items()->whereSku($request->sku)->first();
 
        if (! $item) {
            return "No {$request->sku} here. Read the SKU back to me.";
        }
 
        return "{$item->sku} is now {$item->adjust($request)->on_hand}.";
    }
}

app/Ai/Tools/IssueRefund.phpclass IssueRefund implements Tool, Approvable
{
    use InteractsWithApprovals;
 
    public function __construct(private readonly Account $account) {}
 
    public function description(): Stringable|string
    {
        return 'Refund an invoice on this account.';
    }
    public function schema(JsonSchema $schema): array
    {
        return ['invoice' => $schema->string()->required(),
                'pence' => $schema->integer()->min(1)->required()];
    }
 
    protected function needsApproval(Request $request): Approval|bool
    {
        return $request->pence > 5000
            ? Approval::required('Refunds over £50 need a person.') : false;
    }
 
    public function handle(Request $request): Stringable|string
    {
        $refund = $this->account->refunds()->create($request->all());
        return "Refunded {$refund->amount} on {$refund->invoice}.";
    }
}
